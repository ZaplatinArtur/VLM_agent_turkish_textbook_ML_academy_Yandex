## Вердикт

Вариант набрал **151/274 (55,11%)**. Point estimate выше frozen page-RAG на 10 ответов и matched direct v2 на 14, но общий paired-сигнал не пересёк 0,05: против page-RAG `40/30`, exact McNemar `p=0,2820`; против direct `32/18`, `p=0,0649`.

Главное ограничение для общего бенча: улучшение целиком сосредоточено в математике.

- Math: **79/139 (56,83%)** против page-RAG 62/139, `+17`, `29/12`, `p=0,0115`; против direct v2 65/139, `+14`, `19/5`, `p=0,00661`.

## Согласие восьми кандидатов и селектор

На 274 задачах выполнено ровно **2 192 candidate-вызова + 274 selector-вызова = 2 466 логических вызовов**.

- Среднее число лексически различных ответов среди восьми: **2,854**; unanimous — 73/274, strict majority — 166/274, plurality tie — 35/274.
- Попарное точное лексическое согласие: **4 076/7 672 = 53,13%**. Нормализация — NFKC, casefold, свёртка пробелов и снятие крайних кавычек; это не семантическая эквивалентность.
- Две candidate-трассы имеют пустой ответ, но финальных пропусков нет.
- На unanimous-задачах итоговая точность 64/73 (87,67%). При восьми разных ответах — 1/10 (10%). Разногласие кандидатов является сильным post-hoc индикатором риска, но не калиброванной вероятностью.
- Финальный ответ совпадает с кандидатом по выбранному индексу в **265/274 (96,72%)**, с хотя бы одним кандидатом — в 269/274 (98,18%). Выбранный индекс указывает на plurality-ответ в 212/274; фактический final является plurality-ответом в 211/274.

## Retry и целостность

Первичный прогон имел одну fail-closed ошибку structured output с `finish_reason=length`; единственный операционный ID — `val_0069`. Задача была повторена compact-профилем с ограниченными схемами и лимитом 900 токенов. Финальный solver содержит здоровую строку: 8 кандидатов, 1 селектор, непустой ответ, без forced answer и без solver error.

Точный overhead неуспешного первого запуска этой задачи не архивирован, поэтому 2 843 423 токена и 2 506 HTTP attempts описывают только финальные успешные solver-трассы и являются нижней границей фактического compute.

Финальная проверка: 274 строки, 274 уникальных ID, 0 solver errors, 0 missing final answers, 0 forced answers, 0 tool calls, 0 `gold_access` violations, 0 запрещённых gold/reference-полей.
