# Качество поиска: два способа разбора корпуса × два поисковых профиля

Замер от 2026-08-14. Сырые отчёты рядом: `hybrid_profile/` и `graph_profile/`,
по три файла на профиль (`*_old.json` — постраничный разбор, `*_new.json` —
поединичный).

## Что сравнивается

| обозначение | что это |
|---|---|
| Постраничный разбор | Tesseract OCR, один фрагмент = одна страница. 42 148 фрагментов |
| Поединичный разбор | страница режется на смысловые единицы (теория / упражнение / разобранный пример / решение). 151 576 единиц |
| Гибридный поиск + кросс-энкодер | слияние плотного (e5-small) и лексического (BM25) поиска по RRF, затем переранжирование дообученным bge-reranker-v2-m3 |
| Граф знаний + эвристика | BGE-M3 и BM25 поверх графа знаний, затем эвристическое переранжирование |

## Условия замера

BGE-M3 ревизии `5617a9f`, кросс-энкодер bge-reranker-v2-m3 с дообученным
адаптером. Глубина отбора кандидатов пропорциональна размеру корпуса (200 и
720), переранжирование топ-100 и топ-360. Попадание засчитывается по
странице-источнику: единица поединичного разбора приводится к своей странице
через `parent_chunk_id`, выдача схлопывается до уникальных страниц до отсечения
по k. Задержка — медиана на запрос, одна Tesla V100.

Конфигурация каждого профиля задавалась переменными окружения в команде
запуска, а не умолчаниями в файлах: `MLA_BGE_M3_ENABLED`, `MLA_RERANK_BACKEND`,
`MLA_BGE_M3_INDEX_DIR`, `MLA_CHUNKS_JSONL_DIR`.

## Выводы

Постраничный разбор выигрывает у поединичного во всех двенадцати сравнениях:
на 6–7 пунктов hit@1 для гибридного профиля и на 5–12 для графового.

Гибридный поиск с кросс-энкодером опережает граф знаний на 22–29 пунктов hit@1
на всех наборах и обоих разборах. Цена — скорость: 735–2293 мс против 48–63.

## Оговорки

Эталон релевантности размечался по страницам постраничного корпуса, что по
построению благоприятствует ему. Величина разрыва вряд ли объясняется только
этим, но точную поправку без переразметки под поединичный корпус не получить.

Карточки знаний, ради которых поединичный разбор и делался, на этом корпусе не
работают: ключей ответов найдено 143 на 151 576 единиц, связывать задание с
решением почти негде. Книги корпуса — сборники ответов, где решение стоит рядом
с заданием, а не отдельным разделом.
