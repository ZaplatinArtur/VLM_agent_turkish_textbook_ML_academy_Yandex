# База для мультиязычности: бенчмарки и корпуса учебников

Дата: 2026-08-10. Что уже скачано и сконвертировано, что откуда брать дальше,
и какие грабли известны заранее.

## Принцип

Всё конвертируется в наш `Task`-контракт (`data/validation.jsonl`-совместимый
JSONL + картинки файлами), чтобы **весь конвейер — runner, семь условий, судья,
отчёты — работал на новых языках без единой правки кода**. Конвертер:
`scripts/fetch_mlbench.py` (реестр внутри — источник правды).

```
python scripts/fetch_mlbench.py --list
python scripts/fetch_mlbench.py tumlu
python scripts/fetch_mlbench.py exams-v --langs German --limit 200
```

## Текстовые бенчмарки

| Бенчмарк | Языки | Объём | Статус |
|---|---|---|---|
| [TUMLU](https://huggingface.co/datasets/jafarisbarov/TUMLU-mini) | 9 тюркских: az, crh, kaa, kk, ky, tt, tr, ug, uz | 5693 задачи | **скачан и сконвертирован**, `data/mlbench/tumlu/` |
| [TR-MMLU](https://arxiv.org/abs/2501.00593) | турецкий | 6200 | следующий кандидат |
| [TurkishMMLU](https://huggingface.co/datasets?search=TurkishMMLU) | турецкий | 10K+ | альтернатива TR-MMLU |
| [Global-MMLU](https://huggingface.co/datasets/CohereLabs/Global-MMLU) | 42 | 590K | широкий охват, но перевод MMLU — не школьный домен |
| Belebele | 122 | 900/язык | понимание текста, годится и для ретрив-оценки |

TUMLU выбран первым сознательно: школьные вопросы, написанные носителями
(не перевод), тот же домен, что наши 274 задачи, и тюркская семья — прямой
ответ на вопрос «выучили мы турецкий или школьный навык». В казахском/уйгурском
есть LaTeX-формулы — наш промпт это уже умеет. У 45-задачных dev-сплитов есть
CoT-решения — годятся как few-shot или референс для судьи.

## Мультимодальные бенчмарки (отдельно, как просили)

| Бенчмарк | Языки | Объём | Особенность |
|---|---|---|---|
| [EXAMS-V](https://huggingface.co/datasets/Rocktim/EXAMS-V) | 11 (ar, bg, zh, hr, en, fr, de, hu, it, sr, es) | 20 932 | **вопрос = скриншот экзаменационного листа** — наш сценарий «ленивый школьник» один в один; Apache 2.0 |
| [Kaleidoscope](https://huggingface.co/datasets/CohereLabs/kaleidoscope) | 18 | 20 911 (55% требуют картинку) | in-language экзамены от носителей; лицензия per-item — фильтровать перед публикацией |
| [M3Exam](https://arxiv.org/abs/2306.05179) | 9 | 12 317 (23% с картинками) | реальные выпускные экзамены трёх уровней; данные на GitHub под паролем (анти-крауплинг), не на HF |

EXAMS-V для нас главный: это буквально наш формат входа (`input_format:
screenshot of a book` — 291 из наших 298 задач такие). Прогон на нём проверяет
ровно тот пайплайн, что у нас в проде. Конвертер готов, проба качается
(стриминг тяжёлый — картинки до 6726px шириной; для полного языка лучше качать
parquet целиком, не стримом).

Kaleidoscope — вторая очередь: широта (хинди, бенгальский, телугу, непальский —
низкоресурсные) и честное происхождение. В конвертере сохраняются `_license`,
`_source` и `_needs_image` для фильтрации.

## Оценка без судьи

Все три бенчмарка — multiple choice, то есть **считаются точным совпадением на
100% задач, судья не нужен вообще**. Это снимает главное ограничение нашей
метрики (у нас 72 задачи из 274 требуют судью) и делает мультиязычные прогоны
дешёвыми: exact-match скрипт уже есть.

## Корпуса учебников по языкам (для ретрива)

Наш образец — ÖdevJet (42K страниц, скрейпер + построчная чистка). Аналоги:

| Язык | Источник | Что там |
|---|---|---|
| Азербайджанский | [e-derslik.edu.az](https://www.e-derslik.edu.az) — госпортал Минобра | все учебники 1–11 классов, PDF/EPUB3, свободный доступ |
| Казахский | okulyk.kz / opiq.kz — гос. электронные учебники | 1–11 классы |
| Узбекский | eduportal.uz (раздел kitob) — Минобр | учебники по классам, PDF |
| Кыргызский | [портал Минобра](https://iite.unesco.org/combating-covid-19-together-we-are-on-the-move/national-digital-platforms) (lib.kg / ibilim) | 1–11, кыргызский/русский/узбекский |
| Английский | OpenStax | CC-BY, полностью легально, качественный STEM |
| Хинди/английский | NCERT (ncert.nic.in) | официальные PDF всех классов, свободная раздача |
| Русский | учебники в открытом доступе ограничены | низкий приоритет |
| Турецкий | **уже есть**: ÖdevJet 27 220 чистых страниц + официальные PDF МЕБ (meb.gov.tr, eba.gov.tr — allowlist из веб-роутера Максима) | готово |

План снятия: у госпорталов тюркских стран учебники лежат PDF-файлами — это не
скрейпинг HTML как ÖdevJet, а скачивание + извлечение текста (pdfplumber /
trafilatura не нужен). Наш `prepare-corpus → build-bm25` дальше без изменений.
Приоритет — азербайджанский и казахский: пересекаются с TUMLU, дают связку
«бенчмарк + корпус» для полноценного agent_rag на новом языке.

**Лицензии:** для внутреннего ретрива (индекс, не публикация) риск минимален;
публиковать корпуса нельзя без проверки. OpenStax и NCERT — свободные.

## Грабли, о которых знаем заранее

1. **Утечка.** TR-MMLU/TurkishMMLU собраны из тех же турецких экзаменов, что
   наши 274 задачи. Перед любыми выводами — дедупликация по нормализованному
   тексту вопроса.
2. **Язык ответа.** Уже видели срыв рассуждения в английский на турецком
   вопросе. На новых языках будет чаще (казахский/уйгурский слабее в модели).
   Нужен автоматический детектор языка ответа — алфавит + стоп-слова, копейки.
3. **Промпты.** Наши промпты v2_cot — на турецком. Для честного сравнения
   нужен либо английский нейтральный вариант, либо перевод на язык задачи;
   это отдельное решение, его надо зафиксировать ДО прогонов.
4. **Пароль M3Exam** — данные закрыты от краулеров, качать руками с GitHub.
5. **Kaleidoscope** местами CC-BY-NC — в отчёты можно, в релиз данных нет.
