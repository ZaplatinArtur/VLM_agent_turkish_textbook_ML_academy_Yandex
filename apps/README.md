# Приложения

## Каноническое приложение

[`vlm-analytics/`](vlm-analytics/README.md) — текущая desktop-аналитика. Новые
функции, импортеры, тесты и сборки добавляются только туда. Скрипты экспериментов
также используют путь `apps/vlm-analytics/main.py`.

## Legacy snapshot

`vlm_analytics/` — более ранний snapshot приложения, сохранённый после объединения
веток. Он не является второй активной реализацией. Не синхронизируйте изменения в
оба каталога вручную и не добавляйте в legacy-копию новые функции.

Удалять или переносить snapshot следует отдельным изменением после проверки
внешних ссылок и сохранённых build-инструкций.
