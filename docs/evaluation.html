Одинаковые задания, фиксированная модель и слепая проверка: меняется только доступный агенту источник знаний.

ЧТО МЫ
СРАВНИВАЕМ.

Основной вопрос — улучшает ли поиск по учебникам качество относительно той же модели без инструментов и с веб-поиском.

B0

Без инструментов

Модель видит только задание и решает его самостоятельно.

WEB

Веб-поиск

Агент может обратиться к открытому интернету за внешними фактами.

RAG

Поиск по учебникам

Агент получает релевантные фрагменты из фиксированного корпуса.

=

Фиксируем условия

Для сравниваемых режимов одинаковы набор заданий, версия модели, параметры генерации, формат ответа и судья.

МЕТРИКИ
ОТВЕТА.

Одна цифра не объясняет изменение: вместе с точностью считаются направление эффекта, ошибки и стоимость.

01

Строгая точность

Доля полностью правильных ответов среди всех заданий, включая ошибки запуска.

02

Точная проверка

Числовые и короткие ответы дополнительно сверяются детерминированно после нормализации.

03

Оценка судьёй

Слепая модель-судья видит вопрос, эталон и ответ, но не знает режим агента.

04

Парная разница

Для каждого задания фиксируется победа, проигрыш или ничья нового режима.

05

Предметные срезы

Результаты отдельно считаются по предметам и покрываемой корпусом части.

06

Надёжность

Ошибки агента, задержка, число вызовов поиска и расход токенов входят в отчёт.

ЗАЩИТА ОТ
СМЕЩЕНИЙ.

Протокол отделяет реальный рост качества от случайной вариации и удобной фильтрации ошибок.

ЗНАМЕНАТЕЛЬ

Ошибки считаются неправильными

Пустой ответ, ошибка агента и ошибка формата не исчезают из метрики. Нечитаемые эталоны отмечаются отдельно.

СЛЕПОТА

Судья не знает режим

Из входа удаляются названия инструментов и служебные признаки, которые могут подсказать происхождение ответа.

КАЛИБРОВКА

120 ответов

После завершения всех режимов собирается стратифицированная выборка для проверки согласия судьи с человеком.

НЕОПРЕДЕЛЁННОСТЬ

95% доверительный интервал

Парная разница точности сопровождается бутстреп-интервалом, а не только одной итоговой цифрой.

!

Ручной разбор нужен точечно
