Как задание проходит от входного изображения через маршрутизацию, решение и поиск до единой оценки.

ЧЕТЫРЕ
КОНТУРА.

Компоненты разделены так, чтобы один и тот же набор заданий честно проходил через разные режимы.

01 · АГЕНТ

Единый запуск

Загружает задачи, выбирает режим, сохраняет ответ, шаги решения, вызовы инструментов и ошибки.

02 · ПОИСК

Корпус учебников

Находит кандидатов, объединяет сигналы и повторно ранжирует фрагменты перед передачей агенту.

03 · ОЦЕНКА

Слепая проверка

Сравнивает ответ агента с эталоном по одинаковому протоколу и считает строгую точность.

04 · АНАЛИТИКА

Разбор результата

Собирает предметные срезы, ошибки, историю поиска и сравнение экспериментальных режимов.

05 · ДАННЫЕ

Общие контракты

Задание, изображение, найденный чанк и результат описаны строгими Pydantic-схемами.

06 · ИСТОЧНИКИ

Официальный ответ

При надёжном точном совпадении система возвращает ключ без вызова модели.

ПУТЬ
ОДНОЙ ЗАДАЧИ.

Главная точка сравнения — режим решения; формат входа и оценки остаётся одинаковым.

03Выбрать режим агента
04Решить или вызвать поиск
05Сохранить полный след
06Передать ответ судье
07Построить отчёт
