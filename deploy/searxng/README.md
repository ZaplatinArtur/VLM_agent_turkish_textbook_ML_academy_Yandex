# SearXNG для B1

GPU не нужен — инстанс поднимается где угодно, хоть на ноутбуке.

```bash
cd deploy/searxng
SEARXNG_SECRET=$(openssl rand -hex 32) docker compose up -d
python ../../scripts/probe_searxng.py --url http://localhost:8080
```

В `.env` прогона: `MLA_SEARXNG_URL=http://<хост>:8080`.

## Проверять перед каждым прогоном

`probe_searxng.py` берёт из логов реальные запросы модели, которые в прошлый раз
вернули пустоту, и прогоняет их через инстанс. Возвращает 1, если пустых больше
20% — это гейт: при непройденном гейте прогон измерит неисправность бэкенда, а
не поведение модели. Ровно это и случилось с `b1_deep` (71% пустых).

## Что важно знать про движки

Главное — **ширина пула, а не настройки отдельных движков**. Измерено полным
повтором всех 540 запросов модели:

| Конфигурация | Пустых из 540 |
|---|---|
| шесть движков (ставка на duckduckgo) | 277 (51%) |
| четырнадцать движков, включая мета | **29 (5%)** |

В первом случае duckduckgo был единственным добытчиком: пока он жив — пусто
0 из 240, как только уходит в капчу — 277 из 300. Во втором семь движков лежат
почти постоянно (google cse, mojeek, startpage, yandex — все 540 запросов), и
это никак не мешает: выдачу подхватывают bing и мета-движки.

Плюс пауза между запросами (`MLA_SEARX_MIN_INTERVAL_S`, по умолчанию 3 с) и кэш
повторов — в прогонах 26% запросов повторялись.

Оставшиеся 5% пустых — тоже нестабильность, а не отсутствие материала: при
повторе нашлись все 29 до единого (7 пустых попыток из 87). Поэтому одиночную
пустую выдачу нельзя принимать за результат — её надо переспрашивать, чем и
занимается лестница эскалации в клиенте.

Важно: отвалившиеся движки сами по себе не означают поломку. На живой пробе
brave и startpage лежали на всех 25 запросах, и при этом 24 запроса вернули
результаты — выдачу давали остальные. Поэтому клиент считает бэкенд сломанным
только тогда, когда пустота идёт на инстансе, который давно ничего не отдавал.

## Если пустых много

1. Добавить движков в `settings.yml` — это даёт больше всего (61 общий движок
   доступен в образе, включена четверть). Особенно мета-движки.
2. Дать инстансу отлежаться 10–15 минут — баны движков временные.
3. Увеличить `MLA_SEARX_MIN_INTERVAL_S`.
4. Проверить, что `json` есть в `search.formats` — без него API молча пуст.

Остановить: `docker compose -f deploy/searxng/docker-compose.yml down`.
