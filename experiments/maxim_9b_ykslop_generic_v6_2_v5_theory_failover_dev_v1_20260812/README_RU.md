# Pre-outcome failover V6.2 -> V5 theory

Правило зафиксировано до появления атомарного файла предсказаний V6.2 и до его
оценивания. Для каждой строки используется ответ V6.2 только при полном строгом
успехе его публичного контракта. При отсутствии строки, дубликате content hash,
transport/schema/model-contract ошибке применяется уже зафиксированный ответ
V5 `local_textbook_theory_bm25`.

Содержательное разногласие не арбитрируется. Confidence, gold, outcome и task ID
не являются входами правила. Идентификатор V5 использован только один раз для
внешнего выравнивания с публичным DEV при создании обезличенного fallback-файла;
в замороженном runtime-артефакте идентификаторов нет.

Сначала запускаются `test_failover_rule.py` и синтетический `dry_run.py`, затем
`prepare_freeze.py` и `prepare_private_score_freeze.py`. Реальный `run_failover.py`
можно запускать только после атомарного завершения V6.2, передав SHA его completion.
